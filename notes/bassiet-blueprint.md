# Bassiet blueprint (v16, 17/11/2026) — no spoilers

Live app: https://claude.ai/artifact/DDmJuv6a2agDv383HcCPvH (multi-file Claude artifact, vanilla JS; capabilities db + assets + Google Drive connector [search_files, create_file, trash_file]). Source: app/ in this repo.

## Files
- index.html: all CSS (tokens, dive world `:root[data-world="dive"]`, figures, duels), inline subset fonts, charset/viewport meta, script order, PWA head injection.
- bank1–9.js: Atlas (186 concepts, 424 links, 101 chains, 49 predict, 79 compare). links.js ties chapters to Atlas sites (first site = chapter's main site, tags misses) and re-applies after load.
- story.js (SPOILERS), depths.js (16 depths, strata, bosses with intro/win/lose, tease, topic).
- book1a … book16b.js plus bookx1.js / bookx2.js (new strata pushed into DEPTHS at load). 78 chapters, ~59,000 words, 522 questions.
- figs.js … figs7.js: 29 interactive figures, `FIG[id]={title,def,ctrl,view}`, shared `CT.figKit`, `CT.figNarrow()`.
- app-core.js (storage, setDoc contract, Citrus status, Drive folder resolver), app-today.js (nav, routes, Atlas), app-practice.js (Practice, Plates, Hull), app-dive.js (dive home, depths, reader, stain tests, re-stains, duels, dive log, weak points, Yuzu export, radio, Host file, ending, look/sound).
- sw.js (generated by tools/gen-sw.js), manifest.json, icons.

## The owner's answers
- A microscopic, extremely dark and mysterious adventure. Bassiet is the probe (the word just sounds like a tool).
- A ward doctor on the radio with a horrifying twist the owner must NOT be told.
- The Host is a mystery; the truth is revealed over time until the climax.
- Textbook-depth content with interactive illustrations, deep lore, more depths.
- Game layer: gates and seals, boss duels, weekly report card. Smart help: weak-point finder, mastery that fades, send misses to Yuzu.
- Never copy text or images from Pathoma or other review books; original wording only.

## Status
- Chapters: topic kicker, stratum name as title, epigraph, sections with five stains (Violet path, Green micro, Blue pharm, Teal bio, Rose phys) toggled from a sticky lamp bar, REMEMBER boxes, tables (cards on phones), 5–7 question stain test (60% stains it), Atlas sites.
- Options shuffled everywhere (stable per view, scored by original index); keys balanced in source; every question has subject `d` and concept `c`.
- Gates: a depth opens when its boss above is beaten. Once a boss is won the seal stays broken; strata added later show as optional.
- Duels: HP ≈85% of a 12-question pool (final 70% of 24), hull 4 (final 5), double strike from 5 in a row, recent misses first, per-boss lines, duel clock 40 s / 80 s / off, pauses when away.
- Fading: first fade 3/5/7 days by score, then ladder; failed re-stain drops 2 levels; re-stain locked for unopened depths.
- Dive log: week starts Sunday (setting), practice counts, new players get a welcome line.
- Story: 172 transmissions, 20 Host file entries, ending at #end; home plays at most 6 new lines in order; radio log oldest first.
- Storage: `CT.setDoc` resolves true/false with optimistic update and rollback; loading gate until db arrives; parallel capability loading; focus kept across re-renders; offline after first visit.
- Drive (v16): folders found by Drive id, then new-layout name, then old path (`CT.driveFolder`); never creates/moves folders. status.json carries `drive.byTag:true, method:'folder-id'`.
